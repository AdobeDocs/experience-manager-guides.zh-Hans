# MCP — 扩展对受管技术内容的访问

了解模型上下文协议(MCP)如何让AI支持的体验通过自然语言请求与AEM Guides安全交互，同时遵守现有的AEM访问控制和权限。 在本次研讨会中，我们将介绍MCP体系结构、配置、身份验证和安全模型，演示当前支持的功能，并探索实际用例、当前边界和关键注意事项。 此外，还介绍了AEM as a Cloud Service和内部部署/AMS环境的部署注意事项，演示了支持MCP的客户端如何与AEM Guides连接，并讨论了MCP与Adobe更广泛的AI功能配合使用的场合。


## 会话概述

在本课程中，您将学习如何设置、配置和使用AEM Guides MCP
