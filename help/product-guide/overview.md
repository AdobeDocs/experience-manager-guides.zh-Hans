# Experience Manager Guides文档

Experience Manager Guides是一款企业级CCMS，它在本机DITA中支持结构化创作、多渠道发布和内容生命周期管理。

**部署：** [!BADGE Cloud Service]{type=Positive} [!BADGE 内部部署]{type=Informative}
