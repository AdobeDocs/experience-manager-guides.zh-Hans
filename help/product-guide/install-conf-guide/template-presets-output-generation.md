# 配置用于生成输出的模板预设

>[!NOTE]
>
> 从2026.08.0版开始，Experience Manager Guides as a Cloud Service中提供了模板预设。 请联系您的客户成功团队以启用此功能。

模板预设允许管理员跨多个DITA映射标准化输出预设配置。 您可以将预设定义为模板并将其应用于与文件夹配置文件关联的所有映射，而不是为每个映射单独配置相同的输出预设。

此功能可帮助您维护跨项目的一致发布配置，并减少手动配置工作。

## 好处

使用模板预设具有以下优势：

- 确保跨多个映射的发布配置一致。
- 通过消除重复的预设配置来减少手动操作。
- 允许集中管理输出预设设置。

## 支持的输出类型

除以下输出预设类型之外的所有输出预设类型都支持模板预设：

- Edge Delivery Services
- 知识库
- SCORM

## 创建和管理模板预设

>[!NOTE]
>
> - 模板预设只能由&#x200B;**管理员**&#x200B;和&#x200B;**文件夹配置文件管理员**&#x200B;创建和管理。
> - 模板预设用于配置管理，不能直接用于生成输出。

1. 配置要用于文件夹的文件夹配置文件。
2. 从映射控制台中为关联的文件夹打开&#x200B;**输出预设**。
3. 创建或选择要用作模板的输出预设。

   >[!NOTE]
   >
   > 创建或选择要用作模板的输出预设时，请确保已将其添加到当前文件夹配置文件中。

4. 从预设的&#x200B;**选项**&#x200B;菜单中选择&#x200B;**设置为模板**。

   ![](assets/template-preset.png){width="650"}

   所选输出预设被转换为模板预设。 模板预设通过模板图标进行标识，从而与常规预设有所区别。 要删除模板状态，请随时从模板预设的&#x200B;**选项**&#x200B;菜单中选择&#x200B;**取消设置为模板**。

   ![](assets/unset-as-template.png){width="650"}

5. 从模板预设的&#x200B;**选项**&#x200B;菜单中选择&#x200B;**应用预设更改**&#x200B;以将更新的预设设置应用于所选文件夹配置文件中的所有现有映射。

   **应用预设更改**&#x200B;对话框打开。

   ![](assets/apply-preset-change.png){width="350"}

6. 要覆盖现有预设，请选中&#x200B;**覆盖现有预设**&#x200B;复选框，然后选择&#x200B;**确定**。 覆盖将更新预设，但不会修改目标预设中的基线、条件预设、DITAVAL、主题列表或发布上下文设置。 这些设置保持不变。

   将打开&#x200B;**确认操作**&#x200B;对话框，其中指示预设更改应用到多少映射。

   ![](assets/confirm-preset-change.png){width="350"}

7. 选择&#x200B;**确定**。

更改将应用于关联文件夹中所有映射中的所有预设。

>[!NOTE]
>
> 在关联的文件夹中创建新映射时，模板预设的本地副本也将可用于该新创建的映射。


## 输出生成行为

模板预设是配置模板，不适用于直接发布。 将预设标记为模板时：

- 生成输出不可用。
- 模板预设无法用于发布。
- 如果为模板预设生成的现有输出是在将预设转换为模板之前创建的，则这些输出仍可访问。
