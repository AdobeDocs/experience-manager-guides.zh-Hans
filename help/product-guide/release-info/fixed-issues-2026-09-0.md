# 修复了2026.09.0版本中的问题

本文介绍Adobe Experience Manager Guides as a Cloud Service 2026.09.0版本中修复的各个方面的错误。

有关新增功能和增强功能的详细信息，请查看[2026.09.0版本中的新增功能](./whats-new-2026-09-0.md)。

了解2026.09.0版本[&#128279;](./upgrade-instructions-2026-09-0.md)的升级说明。

## 编辑器2.0

- 将表从创作模式复制并粘贴到创作模式会删除`colwidth`等属性以及在`colspec`上定义的任何其他属性，从而导致列宽设置丢失。 （指南 — 52916）
- 在表单元格`<entry>`中的内联标记被删除之前输入的空格。 （指南 — 49144）

## 创作

本节介绍在创作中修复的编辑器1.0和编辑器2.0共有的错误。

- 在低分辨率屏幕上，当从工具栏插入关键字时，“插入关键字”对话框无法显示，而在使用&#x200B;**更多**&#x200B;选项时，该对话框会按预期打开。 （指南 — 48304）
- 使用空规则文件配置架构验证时保存主题会显示不准确、通用的错误消息。 （指南 — 48106）
- 使用文本节点上下文的架构规则不会触发验证。 （指南 — 14500）
- 使用&#x200B;**Web链接**&#x200B;选项插入交叉引用会添加`scope=local`链接并修改`href`值，而不是按预期插入`scope=external`。 （指南 — 48457）
- 保存引用映射会导致引用断开，而不是当一个作者移动引用的映射而另一个作者同时在未保存的映射中添加对它的引用时解析为正确的映射。 （指南 — 47467）

## 资产管理

- 资源状态API不会为路径包含逗号的资源返回正确的状态。 （指南 — 49065）
- Assets管理员搜索边栏中的DITA元素过滤器不应用输入的值，因此搜索结果不会被过滤。 （指南 — 48450）
- 在多种情况下（包括某些文件类型、缺少元数据的资源和大型报表），版本清除实用程序无法完成，而无法完成清除并生成准确的报告。 （指南 — 43453）
- 在Assets UI中，使用移动操作将具有基于GUID的文件名的资源重命名为其他GUID，并将资源的原始唯一GUID替换为新的GUID。 （指南 — 43006）

## 发布

- 当使用针对较旧版本的基线生成AEM Sites（具有复合组件映射）输出时，页面内容正确显示较旧版本，但页面元数据显示的是当前版本。 （指南 — 49325）
- 使用批量激活来复制页面时，复制跟踪属性仅在根页面上设置，而不是在子页面上设置，因此难以确定自上次复制以来更改了哪些内容。 （指南 — 37871）
- 当“创建/编辑基线”对话框中的&#x200B;**标签**&#x200B;字段首次收到焦点时，粘贴或键入第一个字符无法正确过滤自动完成建议，并且该字段显示所有建议而不是过滤的结果。(GUIDES-50143)
- 分支筛选会为用作`keydef`的不需要的主题生成额外页面（这些主题由DITA-OT标记`resource-only ="true"`）。 （指南 — 19701）
- 映射集合为尚未生成的预设启用&#x200B;**发布**&#x200B;选项。 （指南 — 50510）
- 当新创建的映射集合没有发布记录时，发布历史记录部分不显示占位符文本。 （指南 — 50366）
- 在本机PDF预设上应用ICC颜色配置文件会导致输出生成失败，并且即使使用直接配置文件路径，CMYK颜色也不会正确呈现。 （指南 — 47137）
- 在原生PDF预设上配置的出血设置未反映在生成的输出中。 （指南 — 47034）
- 表连续的&#x200B;**Text before break**&#x200B;字段仅呈现本地化的字符串，不会替换页码占位符。 （指南 — 32872）
- ICC配置文件浏览器错误地显示DITA文件，而不是仅显示ICC文件。 （指南 — 25017）
- 草稿注释未在本机PDF输出中渲染。 （指南 — 47044）
- 置于`title`元素内的草稿注释意外出现在已发布的输出中。 （指南 — 10686）
- 在“地图”功能板中，选择其他预设会触发获取对等链接的调用，从而导致其他处理。 （指南 — 53703）

## 翻译

- 使用XLIFF项目启动翻译会创建一个从不变为进行中状态的空项目。 （指南 — 51759）
- 使用资产移动操作将内容从一个语言文件夹移动到另一个语言文件夹，会阻止作者在“翻译”面板中选择要翻译的内容。 （指南 — 49386）
- 使用&#x200B;**添加到现有翻译项目**&#x200B;选项发送要翻译的资产，而同一项目的其他翻译请求（新项目创建或&#x200B;*添加到现有*&#x200B;请求）仍在处理导致冲突的结果。 （指南 — 49354）

## 基准线

- 删除基线后或仍在创建动态基线时，预设保存的基线选择错误地显示为&#x200B;*无基线*。 （指南 — 52690）

## 审阅

- 打开“审阅”面板或应用项目过滤器需要一些时间来加载任务列表。 （指南 — 48893）

## 报告

- 为包含大量主题的地图生成“断开链接”报告会导致报告界面停留在&#x200B;**无限期获取断开链接的详细信息**&#x200B;消息，从而使浏览器无响应并最终导致其崩溃。 （指南 — 37845）

## 学习内容

- 使用带有自定义标题的HTML或学习模板创建新学习主题时，主题标题未出现在自定义标题中。 （指南 — 52343）
- 课程测验的计算准确度百分比与预期值略有不同。 （指南 — 52346）
- 对于课程，在尝试测试时，分数与预期的计算分数略有不同。 （指南 — 52345）

## 已知问题

Adobe发现了2026.09.0版本的以下已知问题：

- 更改已锁定主题的文档状态将刷新整个文档。 （指南 — 53905）
- 使用基线功能预览时，对于大图（超过10,000个主题）或具有大数`keydefs`的图（例如，100 `keydefs`和3,500个主题）的预览请求超时。 （指南 — 54147）
- 对于数据库服务器，当预览包含不带`href`的`keydef`的映射时启用了“使用基线预览”选项，但未解析`keydef`。 （指南 — 53878）
- 在图像映射资产上配置的热点区域在预览模式下不具有交互性，导致作者无法在发布之前验证热点链接。 (GUIDES-53398)<br>**解决方法**：插入要转换为图像映射的图像，从上下文菜单中选择&#x200B;**编辑图像映射**，然后配置热点链接。
- 当在打开映射时将具有现有基线的映射移动到其他文件夹时，在“预览”模式下将选中&#x200B;**使用基线预览**&#x200B;切换开关，但该基线不再出现在下拉列表中。 (GUIDES-54284)<br>**解决方法**：您可以关闭并重新打开地图来解决问题。
- 在新配置的AEM Cloud Service环境(AEM as a Cloud Service SDK)上，尝试创建映射或主题文件导致&#x200B;*无法创建文件*&#x200B;错误或&#x200B;*检索DTD规则时出错*。 (GUIDES-53904)<br>**解决方法**：您可以重新启动AEM Cloud Service环境。
- 当两个作者同时处理同一主题时，锁定已由一位作者打开了一段时间的主题不会刷新元数据属性，例如版本号、标签、文档状态、标记等，即使其他作者更改了这些属性后也是如此，从而导致继续显示过时的值。 (GUIDES-54810)<br>**解决方法**：关闭并重新打开主题以刷新元数据并显示最新值。
