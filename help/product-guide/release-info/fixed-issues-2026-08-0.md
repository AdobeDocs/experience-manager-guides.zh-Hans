# 修复了2026.08.0版本中的问题

本文介绍Adobe Experience Manager Guides as a Cloud Service 2026.08.0版本各个方面修复的错误。

有关新增功能和增强功能的详细信息，请查看[2026.08.0版本中的新增功能](whats-new-2026-08-0.md)。

了解2026.08.0版本[&#128279;](upgrade-instructions-2026-08-0.md)的升级说明。

## 创作

- 从“映射仪表板”中的主题报表访问主题时，无法在编辑器中打开主题。 （指南 — 45277）


## 编辑器2.0

- 将MathML方程式作为`conref`插入时，无法正确呈现。 （指南 — 46601）
- 在`<keydef>`或`<topicref>`内的`<topicmeta>`中复制并粘贴`<keywords>`会导致关键字被插入不需要的外部标记中。 （指南 — 45800）
- 在映射编辑器的断开链接上使用`Ctrl+click`会触发应用程序错误。 （指南 — 45544）
- 将表从Excel电子表格复制并粘贴到新编辑器时，会将所有复制的单元格内容放入单个表单元格中，而不是将其分发到相应的单元格中。 （指南 — 47435）
- 通过`editor_toolbar.json`配置的自定义&#x200B;**导出为PDF**&#x200B;按钮将呈现并在预览模式下保持可单击状态，但单击时不会执行任何操作。 （指南 — 47402）
- MathML和SVG元素不呈现其完整的属性集，从而导致应用于这些元素的自定义CSS类和条件属性中断。 （指南 — 46371）
- 打开包含表的特定主题会添加带有两个新列的意外`<foreign>`标记，即使未对主题进行任何更改也是如此。 （指南 — 46748）
- **Scale**&#x200B;属性不适用于创作视图中的图像。 （指南 — 45996）
- 拖放包含`keyref`的元素会将`keyref`值转换为绝对路径。 （指南 — 45701）
- 在`tgroup`位置插入元素时显示&#x200B;**#text此处不允许出现**&#x200B;警告，导致无法在该位置插入普通表。 （指南 — 47446）
- 添加到词典的字母数字术语仍由AEM拼写检查器标记，而不是被忽略。 （指南 — 48587）

## 资产管理

- 批量资产处理错误地包含内容片段资产，导致处理报表中有错误日志和失败。 （指南 — 47085）
- 在“映射”面板中，如果反复选中和取消选中映射复选框，则子主题加载失败，展开图标消失。 （指南 — 43546）

## 发布

**AEM Sites**

使用复合组件映射发布AEM Sites输出时：

- 在具有复合组件映射的AEM Sites预设中使用新基线时，显示空白的&#x200B;**主题列表**。 （指南 — 46480）
- 指向非DITA资源（如PDF、ZIP、DOCX和图像文件）的交叉引用(`xref`)链接无法正确解析，从而导致生成的页面上的链接断开。 （指南 — 44108）

使用旧版组件映射发布AEM Sites输出时：

- 生成的页面名称中的非英语文件名会被替换为连字符，从而难以识别与其关联的主题或文件。 （指南 — 48387）

**本机PDF**

- 在本机PDF输出中，以`toc="no"`属性标记的主题引用仍包含在目录中，从而导致冗长而混乱的目录。 （GUIDES-37940和GUIDES-20156）

**映射收藏集和批量激活**

Experience Manager Guides 2020.08.0版本中提供的[新地图收集](../user-guide/generate-output-use-new-map-collection-output-generation.md#use-new-map-collection-for-output-generation-beta)功能修复了以下问题：

- 由于网络错误，无法加载包含超过100个映射项的映射集合。 （指南 — 34007）
- 无法从映射收集UI中的文件夹一次选择多个映射。 （指南 — 29581）
- 无法在映射收藏集UI中搜索或筛选映射收藏集。 （指南 — 27723）
- 如果不使用浏览器的返回按钮，则无法关闭批量发布/激活仪表板或导航回&#x200B;**工具**&#x200B;或主页。 （指南 — 26797）
- 无法使用大量地图或语言轻松管理地图收藏集。 （指南 — 21735）
- 无法直接从“映射收藏集”或“批量激活功能板”界面查看或发布生成的输出。 （指南 — 18712）
- 无法使用单个收藏集来生成和激活映射，因为映射收藏集和批量激活功能板管理单独的收藏集集。 （指南 — 12730）

## 审阅

- 在审阅UI中，标记列表显示审阅任务中的所有用户，这使得在评论或回复中选择正确用户变得困难。 （指南 — 33420）
- 在“注释”面板中打开&#x200B;**并排**&#x200B;视图，会在注释版本旁显示工作副本，但窗格不会水平同步滚动，单击注释不会将光标移动到相应的文本。 （指南 — 44083）

## 数据库

- `DatabaseConfiguratorService`在日志中抛出错误，即使未配置或未启用它也是如此。 （指南 — 43481）

## 已知问题

Adobe发现了2026.08.0版本的以下已知问题：

## 创作

- 关闭已移动到其他位置的DITAVAL文件会导致`ERROR IN FETCHING VERSION DETAILS`错误消息。 （指南 — 51420）
- 当存储库文件夹路径以正斜杠结尾时，冲突API失败并导致应用程序错误。 （指南 — 51006）

## 编辑器2.0


- 在“大纲”视图中选择处理指令元素会突出显示整个父标记，而不是选定的元素。 （指南 — 48318）
- 当视图切换到任何其他视图时，编辑源视图中`keyref`内的关键字将破坏该关键字。 （指南 — 49998）
- 包装在`foreign`和`equation`块中的MathML公式会导致多余的间距，即使在调整缩进后，在公式中键入也会导致问题。 （指南 — 46606）
- 启用&#x200B;**显示标记**&#x200B;选项并在编辑器设置中禁用&#x200B;**显示属性**&#x200B;选项时，无法将光标置于`reltable`内的`topicref`内。 （指南 — 46565）

- 在表单元格`<entry>`中的内联标记被删除之前输入的空格。 （指南 — 49144）

## 发布

- 在生成Edge Delivery Services输出后选择&#x200B;**查看输出**&#x200B;将打开一个返回403禁止错误的`hlx.live` URL而不是`aem.live` URL。 （指南 — 51572）
- 从模板工具栏添加图像、超链接或iframe时，`common.plt`页面上会显示无效的组件。 （指南 — 51165）
- 使用`copy-to`属性发布引用主题的映射会从源映射中的相应主题中删除对等作用域链接。 （指南 — 50701）
- 当PDF作为范围设置为`Peer`的`xref`引用时，它发布在AEM网站上（使用旧版组件映射），而不是从交叉映射进行来源。 （指南 — 50213）

**映射收藏集**

- 如果您切换选项卡（例如“存储库”或“概述”），然后返回到映射收藏集页面再删除它，则删除映射收藏集有时失败。 （指南 — 50997）
- 在上一代正在进行时生成相同的预设，将不再显示指示前一代正在进行中的消息。 （指南 — 50523）
- 生成映射后，上次生成时间戳不会在映射收藏集UI中显示或更新，重新添加之前已删除的预设会导致其生成历史记录再次丢失。 （指南 — 50511）
- 从&#x200B;**层代历史记录**&#x200B;中发布将始终发布预设的最新输出，而不是所选的层代。 （指南 — 50508）
- 新创建的映射集合的发布状态不会自动刷新。 （指南 — 50367）

## 翻译

- 使用&#x200B;**仅创建结构**&#x200B;选项启动翻译会返回错误。 （指南 — 51261）

## 审阅

- 对包含隐藏条件内容的文本使用键盘快捷键执行删除线时，也会删除隐藏的内容。 （指南 — 49837）
