# 修复了2026.11.0版本中的问题

本文介绍Adobe Experience Manager Guides as a Cloud Service 2026.11.0版本中修复的各个方面的错误。

有关新增功能和增强功能的详细信息，请查看[2026.11.0版本中的新增功能](./whats-new-2026-11-0.md)。

了解2026.11.0版本[&#128279;](./upgrade-instructions-2026-11-0.md)的升级说明。

## 编辑器2.0

- 当在编辑器中使用痕迹导航选择表行，并从上下文菜单中选择&#x200B;**删除**&#x200B;选项时，将只删除单元格内容而不是删除整行。 （指南 — 56759）
- 从Microsoft Word粘贴表时，将创建标题行单元格，但标题行单元格内容会丢失。 （指南 — 49847）
- 在移动到编辑器2.0之前创建的文件中的跟踪更改未出现在&#x200B;**跟踪更改**&#x200B;面板中。 （指南 — 44777）
- 当使用Ctrl+V将代码从Microsoft Word或类似的文本编辑器粘贴到`codeblock`元素中时，换行符和行首空格将丢失，代码将拼合到一行中。 （指南 — 33247）

## 创作

- 启用Unified Shell后， Adobe Experience Manager Guides标头也会出现在编辑器和映射控制台中。 （指南 — 56812）
- 在Assets UI中，针对非DITA资源显示特定于DITA的操作，例如&#x200B;**查看源**、**编辑主题**&#x200B;和&#x200B;**共享UUID链接**。 此外，**共享UUID链接**&#x200B;为没有UUID的资源生成无效链接。 （指南 — 47043）
- 在“主题方案”面板中，仅从`navtitle`属性中选取显示标题。 即使同时存在`navtitle`元素，也会忽略该元素。 （指南 — 37722）
- 在“存储库”面板的&#x200B;**标题视图**&#x200B;中，名称较长的文件一开始不会显示省略号。 右键单击此类文件后，省略号和上下文菜单会出现在文件最右边，有时会出现部分屏幕外。 （指南 — 37118）
- 在“条件”面板中，条件将根据其值而不是其标签按字母顺序排序。 （指南 — 14593）
- 在输出模板中，打开样式表（如layout.css）时，“样式”面板中不显示&#x200B;**新样式** (+)按钮。 （指南 — 49448）

## 资产管理

- 当您使用&#x200B;**覆盖现有文件**&#x200B;选项上载修改的文件时，如果现有文件没有Guides UUID并且存储在&#x200B;**后处理的忽略路径**&#x200B;下列出的文件夹中，则上载似乎已完成。 但是，不会覆盖现有文件，也不会创建任何新版本。 （指南 — 55866）
- 在书签映射中，当`booktitle`元素包含多个子元素（如`booklibrary`和`mainbooktitle`）时，会在`dc:title`元数据中的值之间添加额外的空格。 （指南 — 28877）

## 发布

- 在映射控制台中，为一个映射生成输出后，打开另一个映射时，**生成**&#x200B;按钮被禁用。 刷新浏览器会再次启用按钮。 （指南 — 54591）
- 在创建目录时，将某些映射发布到具有组件映射的AEM站点会失败并出现错误。 （指南 — 53807）
- 当映射包含具有`navtitle`属性且没有`href`属性的`topicref`元素时，将映射发布到具有组件映射的AEM站点会失败。 在删除生成的站点节点之前，即使删除了元素，后续尝试也会失败。 （指南 — 53707）
- 在包含组件映射的AEM网站输出中，级别2到6的Markdown标题呈现为级别1标题。 （指南 — 51134）
- 对于具有组件映射的AEM站点输出，prolog元数据（如作者、关键字和资源ID）会显示在已发布输出的页面正文中。 （指南 — 44087）
- 将主题发布到ServiceNow时，文章正文包含该主题的简要说明和序言。 （指南 — 47868）
- 当已在ServiceNow中发布的主题再次发布时，将在草稿状态下创建新文章，而不是覆盖现有文章。 （指南 — 37872）
- 当条件预设在发布到Salesforce期间排除主题引用时，即使其余主题已成功发布，输出生成也会报告为失败。 （指南 — 37807）
- 将大型映射发布到Salesforce失败，并出现网关超时错误。 （指南 — 33722）
- 当请求包含的操作数超过25时，将映射发布到Salesforce会失败，并出现超出限制的错误。 （指南 — 33721）
- 在地图仪表板（旧）中，现有条件预设中的“全部添加”**不会选取创建预设后添加或更改的条件值。**（指南 — 45940）
- **输出历史记录**&#x200B;页面中包含警告的日志显示有绿色图标，该图标不表示出现警告。 （指南 — 27000）
- 当映射内容中的任何术语均不引用术语表条目时，输出中不包含术语表。 （指南 — 52964）
- 在附录中引用的子映射中的主题将作为章节而不是附录内容渲染。 （指南 — 52775）
- 当输出语言设置为中文（简体）时，某些简体中文字符会以日语字体呈现。 （指南 — 48094）
- 索引项会丢失子元素（如`keyword`、`ph`和`sup`）的文本。 因此，某些索引标签不完整或为空。 （指南 — 40902）
- 未保留内联`option`元素周围的空格，从而导致相邻的文本显示连接在一起。 （指南 — 40900）

## 翻译

- 在“翻译”页面上，按&#x200B;**标题**&#x200B;进行搜索和排序时，将使用本地化的元数据值，而不是列中所显示的标题。 （指南 — 45396）

## 审阅

- 在&#x200B;**审阅人**&#x200B;页面上，在创建或编辑审阅任务期间，默认情况下将启用&#x200B;**清除选择**、**添加审阅人**、**删除审阅人**&#x200B;和&#x200B;**重新分配审阅人**&#x200B;按钮，即使未选择任何行也是如此。 （指南 — 35125）
- 在AEM收件箱中，会显示与审核任务相关的通知，例如任务分配、收到的反馈、提及以及到期或逾期提醒，并且没有任何项目名称。 （指南 — 10912）
- 在审阅任务中主题的并排视图中，带有删除线的内容在两个视图中以不同的格式显示。 （指南 — 56079）

## 学习内容

- 为大型课程（通常为300 MB到600 MB）生成SCORM输出需要30分钟以上的时间，并且失败时日志中没有错误详细信息。 （指南 — 56101）
- 无法在Experience Manager Guides中设置SCORM输出的完成条件。 （指南 — 55520）
- AVIF格式的图像显示在编辑器中，但发布的输出中缺少图像。 （指南 — 55515）
- `href`属性已从已发布输出中的锚点标记中删除，因此链接不可点击。 （指南 — 55514）

## 平台

- 当用户在文件夹配置文件中被指定为管理员用户，但不是管理员组成员时，他们无法成功添加其他管理员用户。 尽管显示成功消息，但新添加的用户在刷新页面后消失。 （指南 — 50144）

## 已知问题

Adobe发现了2026.11.0版本的以下已知问题：

## 创作

- 从包含相关主题或子映射的模板创建映射时，映射创建可能会间歇性地失败并出现错误，特别是在服务器负载较重时。 （指南 — 58715）

### 编辑器2.0

- **刷新导航标题属性**&#x200B;选项未将`@navtitle`属性添加到DITA映射中的现有`topicref`元素。 （指南 — 54348）

**跟踪更改**

打开&#x200B;**跟踪更改**&#x200B;时：

- 当包含已删除内容的元素被重命名或格式化时，由同一用户进行的嵌套删除并不总是合并到单个条目中。 （指南 — 58429）
- 当其他用户执行嵌套删除时，**跟踪更改**&#x200B;面板有时会显示父元素的不完整内容。 （指南 — 58428）
- 删除其他用户插入的内容时，红色沟槽标记不会出现在左侧。 （指南 — 58418）

### 发布

- 在本机PDF输出中，上标和下标格式未保留在索引条目中。 （指南 — 58349）
- 使用相同的全局预设为不同的映射生成输出时，从上一个映射中选择的主题可能会影响新映射的输出。 （指南 — 58346）
- 当书籍映射包含具有有效`href`的章节和嵌套主题引用时，将映射发布到AEM Sites会导致出现空白页。 （指南 — 58266）
- 从包含未保存更改的预设导航到&#x200B;**输出历史记录**&#x200B;选项卡时，**保存**&#x200B;和&#x200B;**生成输出**&#x200B;按钮保持可见。 （指南 — 57989）
- 为预设配置发布后工作流时，**输出历史记录**&#x200B;中显示的发布持续时间不包括工作流所用的时间。 （指南 — 57856）
- 无法从&#x200B;**输出历史记录**&#x200B;页面取消生成Native PDF输出。 （指南 — 57821）

### 审阅

- 打开在2026.08.0或2026.09.0版本中创建的审核任务可能会导致应用程序错误。 (GUIDES-56583) <br>**解决方法：**&#x200B;在升级到2026.11.0版本之前，完成或关闭在这些版本中创建的所有审阅任务。
